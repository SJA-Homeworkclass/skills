# 📚 香港中小學全學科核心詞彙庫（中英對照與易讀指引）

> **使用原則**：
> 1. 面向 NCS 學生時，優先提供括號雙語對照。
> 2. 面向 SEN 學生時，避免使用抽象術語，多用具象詞（如用「外圍一圈」輔助解釋「周界」）。

---

## 🧮 1. 數學科 (Mathematics)

| 中文術語 | English Term | SEN/NCS 易讀白話解釋 |
|---|---|---|
| **已知條件** | Given Information | 題目告訴我們的資料與數字 |
| **求 / 解** | Find / Solve | 題目要我們找出的答案 |
| **方程 / 未知數** | Equation / Unknown ($x, y$) | 帶有問號或字母的算式 |
| **周界** | Perimeter | 圖形「外圍一圈」的總長度 |
| **面積** | Area | 圖形「裡面鋪滿」的大小 |
| **體積 / 容量** | Volume / Capacity | 盒子「能裝多少空間/水」 |
| **直角 / 銳角 / 鈍角** | Right / Acute / Obtuse Angle | 像書本角的角 / 尖尖的角 / 開開的角 |
| **分數 / 分子 / 分母** | Fraction / Numerator / Denominator | 一份中的幾份 / 上面的數 / 下面的總數 |
| **百分率 / 百分比** | Percentage (%) | 一百份裡面佔了多少份 |
| **比例 / 比率** | Ratio / Rate | 兩樣東西數量的比較 |
| **代數式** | Algebraic Expression | 用字母和數字排成的算式 |
| **坐標** | Coordinates $(x, y)$ | 地圖上的位置（橫走幾步，直走幾步） |

## 🔬 2. 科學 / 常識科 (Science / General Studies)

| 中文術語 | English Term | SEN/NCS 易讀白話解釋 |
|---|---|---|
| **觀察** | Observe | 用眼睛看、耳朵聽、手去摸 |
| **假設 / 預測** | Hypothesis / Prediction | 猜猜看會發生什麼事 |
| **實驗 / 步驟** | Experiment / Procedure | 動手做測試的方法與順序 |
| **控制變因** | Controlled Variable | 保持一樣、不能改變的東西 |
| **獨立變因** | Independent Variable | 我們故意去改變的那一樣東西 |
| **固體 / 液體 / 氣體** | Solid / Liquid / Gas | 硬硬有形狀 / 會流動的水 / 看不見的空氣 |
| **光合作用** | Photosynthesis | 植物吸陽光自己做食物的過程 |
| **導體 / 絕緣體** | Conductor / Insulator | 電/熱容易通過 / 電/熱通不過去 |
| **生態系統 / 食物鏈** | Ecosystem / Food Chain | 大自然中生物互相生活與吃/被吃關係 |

## 🏛️ 3. 歷史 / 中史 / 地理科 (History / Chinese History / Geography)

| 中文術語 | English Term | SEN/NCS 易讀白話解釋 |
|---|---|---|
| **時序 / 年代** | Chronology / Timeline | 事情發生的時間前後順序 |
| **原因 / 誘因** | Cause / Trigger | 事情為什麼會發生 / 導火線 |
| **影響 / 後果** | Impact / Consequence | 這件事之後帶來了好處或壞處 |
| **主要人物 / 統治者** | Historical Figure / Ruler | 歷史故事裡帶頭或做決定的人 |
| **朝代 / 條約** | Dynasty / Treaty | 某個家族統治的時期 / 兩國簽訂的協議 |
| **地圖讀取 / 圖例** | Map Reading / Legend | 看懂地圖上的圖案代表什麼地方 |
| **人口密度** | Population Density | 一個地方住的人擠不擠 |
| **可持續發展** | Sustainable Development | 現在用資源，但留給未來的人也能用 |
